01 THE STORY

Nobody teaches you
how it starts

I'm Yusuf. I'm seventeen, I'm in high school, and I taught myself to write scripts by breaking things on purpose.

It started at sixteen in Roblox Studio. I made chat-style games first — small, text-heavy, mostly for the joke of it. Then I moved on to obby maps: parkour courses you replay fifty times just to beat. I got proper distance records, proper timers, proper level design.

Then I hit the part nobody warns you about. Nobody played them. A game with zero players teaches you something brutal: the hard part was never building it, it was getting anyone to show up. So I deleted the ambition, kept the skills, and went back to playing Roblox like a normal person.

And that's when it actually clicked. I started writing scripts instead of games. Two people made that possible: HalisAnteo and Henne. Everything I know about clean, production-grade scripting came from watching how they worked.

My first scripts lived on Pastebin, pasted into forums at 2am. When I outgrew Pastebin I moved everything to GitHub and started writing things other people could actually use. I planned to script for exactly one game. Now I script for several — and I own Syniox Hub, a server I built from the ground up and one I'm genuinely proud of.

School takes my mornings and evenings. Everything else is code.

05 CHAPTERS

How it went

  1. AGE 16

    Chat games, then obbies

    First Roblox Studio experiments: text-heavy chat games, then parkour courses with real level design, timers and distance records.

  2. THE HITCH

    Nobody played

    Releasing games nobody opened was the most useful failure I've had. I learned the difference between building something and shipping something.

  3. THE PIVOT

    Games to scripts

    I stopped making games and started writing them instead. Same platform, completely different problem — and this time people needed it.

  4. MENTORS

    HalisAnteo & Henne

    Two people shaped how I write code. Watching how they built things taught me structure, naming and why the server never trusts the client.

  5. PASTEBIN → GITHUB

    Scripts worth keeping

    Pasted snippets became a documented library. Everything I write now is structured so the next person — including me — can use it.

  6. 2026 · NOW

    Syniox Hub & high school

    Owning a server people actually join, scripting for several titles, and going to school. Mornings and evenings are school; the rest is code.
